# 文档

本目录存放 CCNBSLib 的使用文档。

| 文件 | 用途 |
|---|---|
| [`CLI.md`](CLI.md) | 安装器用法：命令、镜像、出错码、更新与卸载 |
| [`API.md`](API.md) | `ccnbslib` 公共 API 参考：`decode` / `analyze` / `plan` / `play`、接缝注入、警告码、返回形状；含可直接运行的示例 |
| [`COMPAT.md`](COMPAT.md) | 平台差异：扬声器音高、一个扬声器每 tick 的音符上限、定时粒度、HTTP 配置位置、自定义乐器 |

入门与安装请看仓库根目录的 [`../README.md`](../README.md)。

> 提示：在模拟器上听到的结果与真实游戏可能不同，先看 `COMPAT.md` 里的平台差异。
